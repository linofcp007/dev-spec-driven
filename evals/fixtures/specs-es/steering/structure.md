# Estructura del Proyecto

## Layout
- src/ contiene el código (orders.js, csv.js, cli.js, discount.js)
- test/ contiene un fichero de test por módulo

## Nombres
- Tests llamados `<modulo>.test.js`; el título de cada test empieza por su T-ID.

## Commits
Conventional commits: `type(scope): descripción`.

## Ramas y Revisiones
- main más una rama local por función, integrada con un merge local.
