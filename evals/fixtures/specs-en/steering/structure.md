# Project Structure

## Layout
- src/ holds the code (orders.js, csv.js, cli.js, discount.js)
- test/ holds one test file per module

## Naming
- Files in kebab-case; tests named `<module>.test.js`, each test title starts with its T-ID.

## Commits
Conventional commits: `type(scope): description`.

## Branches & Reviews
- main plus one local feature branch per feature, merged locally.
